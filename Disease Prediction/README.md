## Overview

MedPredict AI is a **full-stack AI healthcare prediction platform** that uses machine learning to assess the risk of three major diseases:

- ❤️ **Heart Disease** (Cleveland UCI Dataset, 13 features)
- 🩸 **Diabetes** (Pima Indians Dataset, 8 features)
- 🔬 **Breast Cancer** (Wisconsin Dataset, 30 features)

The system trains **4 ML classifiers** per disease (Logistic Regression, SVM, Random Forest, XGBoost), evaluates them on multiple metrics, selects the best, and exposes predictions via a RESTful API secured with JWT authentication. Users can view prediction history, compare model performance, and access a personalized dashboard.

## ML Workflow

```
Raw Dataset
    │
    ▼
Data Loading & Inspection
    │
    ▼
Data Cleaning
├── Handle missing values (? → NaN, 0 → NaN for invalid physiological values)
├── Remove duplicates
└── Detect outliers
    │
    ▼
Feature Engineering
├── Target binary encoding
└── Feature selection (use established clinical features)
    │
    ▼
Preprocessing Pipeline (sklearn Pipeline to prevent leakage)
├── SimpleImputer (median strategy)
└── StandardScaler
    │
    ▼
Stratified Train/Test Split (80/20, random_state=42)
    │
    ▼
Train 4 Classifiers
├── Logistic Regression (class_weight='balanced')
├── SVC (probability=True, class_weight='balanced')
├── RandomForestClassifier (n_estimators=100)
└── XGBClassifier
    │
    ▼
Evaluate All Models
├── Accuracy
├── Precision
├── Recall (sensitivity) ← critical for medical
├── F1 Score
├── ROC-AUC
└── Confusion Matrix
    │
    ▼
Select Best Model (by F1 Score)
    │
    ▼
Save Artifacts
├── best_model.joblib  (complete sklearn Pipeline)
├── scaler.joblib      (preprocessor Pipeline)
├── metadata.json      (best model info + metrics)
└── all_metrics.json   (all 4 models' metrics)
    │
    ▼
FastAPI loads models once at startup
    │
    ▼
Predictions served via REST API
```

## Dataset Information

| Dataset | Source | Samples | Features | Target |
|---------|--------|---------|----------|--------|
| **Cleveland Heart Disease** | UCI ML Repository | 303 | 13 | 0=No Disease, 1=Disease |
| **Pima Indians Diabetes** | J. Brownlee / Kaggle | 768 | 8 | 0=No Diabetes, 1=Diabetes |
| **Wisconsin Breast Cancer** | sklearn.datasets | 569 | 30 | 0=Malignant, 1=Benign |

### Heart Disease Features
`age, sex, cp (chest pain type), trestbps (resting BP), chol (cholesterol), fbs (fasting blood sugar), restecg, thalach (max heart rate), exang (exercise angina), oldpeak (ST depression), slope, ca (major vessels), thal`

### Diabetes Features
`Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, Age`

### Breast Cancer Features
30 computed features from digitized FNA images: mean, standard error, and "worst" (largest) values for radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry, and fractal dimension.

## Algorithms

| Algorithm | Description | Strength |
|-----------|-------------|----------|
| **Logistic Regression** | Linear classifier with log-odds | Interpretable, fast |
| **SVM (SVC)** | Maximum-margin classifier | Effective in high-dimensional spaces |
| **Random Forest** | Ensemble of decision trees | Robust, handles non-linearity |
| **XGBoost** | Gradient boosting with regularization | Often highest accuracy |

## Quick Start

### Prerequisites
- Python 3.11+
- Node.js 20+
- MongoDB (local or Atlas)
- [Homebrew](https://brew.sh/) (macOS) for libomp

### 1. Clone the Repository
```bash
git clone <your-repo-url>
cd disease-prediction-system
```

### 2. Install OpenMP (macOS, required for XGBoost)
```bash
brew install libomp
```

### 3. Train ML Models
```bash
cd ml
pip install -r requirements.txt
python train_heart.py
python train_diabetes.py
python train_breast_cancer.py
cd ..
```

### 4. Start the Backend
```bash
cd backend
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your MongoDB URI and SECRET_KEY
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 5. Start the Frontend
```bash
cd frontend
npm install
npm run dev
```

Open **http://localhost:5173** in your browser.

## Training Models

Run each training script from the `ml/` directory:

```bash
cd ml

# Train Heart Disease model (Cleveland UCI dataset - downloads automatically)
python train_heart.py

# Train Diabetes model (Pima Indians dataset - downloads automatically)
python train_diabetes.py

# Train Breast Cancer model (sklearn built-in - no download)
python train_breast_cancer.py
```

Each script will:
1. Download/load the dataset
2. Preprocess (impute missing values, scale)
3. Train 4 algorithms
4. Evaluate and compare
5. Save the best model as `ml/models/{disease}/best_model.joblib`

**Note**: SSL certificate issues on macOS are handled automatically.

## Deployment

### Frontend → Vercel

1. Push code to GitHub
2. Connect repo to [Vercel](https://vercel.com)
3. Set framework: **Vite**
4. Set root directory: `frontend/`
5. Set environment variable: `VITE_API_URL=https://your-backend.railway.app`
6. Deploy

### Backend → Railway

1. Go to [Railway](https://railway.app)
2. New Project → Deploy from GitHub
3. Select `backend/` as root
4. Add environment variables:
   ```
   MONGODB_URI=mongodb+srv://...
   DB_NAME=disease_prediction_db
   SECRET_KEY=your-production-secret-key
   CORS_ORIGINS=["https://your-frontend.vercel.app"]
   ML_MODELS_PATH=/app/ml_models
   ```
5. Add volume for ML models or upload them separately

### Database → MongoDB Atlas

1. Create account at [MongoDB Atlas](https://www.mongodb.com/atlas)
2. Create a free M0 cluster
3. Create database user
4. Whitelist all IPs (0.0.0.0/0) or specific ones
5. Get connection string: `mongodb+srv://user:pass@cluster.mongodb.net/`
6. Use as `MONGODB_URI` in backend
